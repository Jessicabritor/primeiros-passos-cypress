# Cypress Test Automation


This project uses Cypress to automate end-to-end tests for a login feature and a user information update feature.

Cypress is a JavaScript-based end-to-end testing framework that enables tests to be written and executed directly in a real browser.



## Installation

Install the project dependencies by running:
```bash

npm install
```

> **Note:** Node.js must be installed on your machine before running the project.



# Running the Tests
```bash
#To open the Cypress Test Runner:

npx cypress open



#To run the tests directly from the command line:

npx cypress run
```
